# Валидация Organization — 23 октября 2026

Результат: разметка внедрена в исходный HTML 139 содержательных страниц. Проверены 369 блоков JSON-LD; 91 предложение товара связано с единой организацией через `offers.seller.@id`. Ошибок не обнаружено.

## Что внедрено

- `@type: Organization`, стабильный `@id: https://www.molberty.ru/#organization`.
- Название «Мольберты.ру», альтернативное название «Мастерская Иванова Д. В.», описание деятельности, URL, e-mail, розничный телефон.
- `PostalAddress`: Мытищи, Московская область, Проектируемый проезд 4530, строение 2, завод «СпецМашМонтаж», `addressCountry: RU`.
- Две точки `ContactPoint`: розничные и оптовые продажи, с соответствующими телефонами, e-mail и русским языком общения.
- `logo`: существующий знак сайта в отдельном SVG 512 × 512. Внешний вид страниц не менялся.
- `seller` в `Offer` и `AggregateOffer`; ссылка сохраняется при выборе опта, розницы и комплектации.

Контакты сверены с [исходной страницей компании](https://www.molberty.ru/contacts). Неподтверждённые реквизиты и социальные профили не добавлялись. Данные организации хранятся в `data/organization.json`, примеры актуального JSON-LD для 16 страниц — в `qa/generated-schema.json`.

## Внешний Schema.org Markup Validator

Полный HTML локальных страниц передан в [официальный валидатор Schema.org](https://validator.schema.org/) через вкладку «Фрагмент кода».

| Страница | Ошибки | Предупреждения |
| --- | ---: | ---: |
| Главная `/` | 0 | 0 |
| Контакты `/contacts/` | 0 | 0 |
| Товар `/product/bolshoy-stankovyy-buk/` | 0 | 0 |

На карточке товара организация объединяется по `@id` с сущностью продавца внутри `Product`. Это единый объект, а не две разные организации.

## Проверка всего локального сайта

- 139 из 139 страниц содержат ровно один одинаковый `Organization` в `<head>`.
- На 25 страницах переадресаций разметка организации не размещается.
- Все 369 блоков JSON-LD корректно разбираются; разметка `BreadcrumbList` и `Product` сохранена.
- Все 91 ссылки `seller` разрешаются в организацию на соответствующей странице.
- Названия четырёх типизированных объектов и 23 применения свойств организации проверены по актуальному официальному словарю Schema.org, включая наследуемые домены и допустимые типы значений.
- URL абсолютные, контакты совпадают с данными сайта, SVG существует и имеет размер 512 × 512.
- Генератор выдаёт ту же организацию и те же схемы всех 91 товаров, что включены в готовые HTML.
- В браузере проверены главная, контакты и товар с JavaScript и без него; три изменения цены сохраняют `seller`. Логотип отдаётся локальным сервером с HTTP 200 и типом `image/svg+xml`.
- Общая команда `npm run check` пройдена.

Постоянная проверка: `python3 scripts/validate-organization.py` (также включена в `npm run check`). Машинный отчёт — `qa/organization-schema-validation.json`.

## Границы проверки и перенос на CMS

Проверялся код подготовленной локальной версии, не опубликованная версия molberty.ru. Внешний сервис подтвердил корректность разметки в режиме проверки кода. Проверка доступности нового логотипа выполнена на локальном сервере; новый файл необходимо перенести вместе с сайтом.

У прототипа сохранён действующий `noindex, nofollow`. Разрешение индексации и проверку опубликованных URL выполняют при запуске после миграции. Валидность Schema.org сама по себе не подтверждает индексацию или появление расширенного результата Google. При реализации использованы [рекомендации Google по Organization](https://developers.google.com/search/docs/appearance/structured-data/organization) и [словарь Organization](https://schema.org/Organization).
