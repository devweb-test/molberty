# Блоки главной для WordPress

Модуль для будущего переноса сайта, WordPress 6.3+, PHP 7.4+. CMS в статическом макете не установлена.

1. Скопировать папку `molberty-home-blocks` в `wp-content/plugins/` и активировать плагин. Также можно установить подготовленный отдельный ZIP через раздел Плагины → Добавить плагин → Загрузить плагин.
2. В редакторе главной страницы после отзывов добавить блоки **Мольберты.ру - Кейсы** и **Мольберты.ру - Творчество объединяет**. Каждый блок изначально выключен.
3. Через обычные блоки WordPress заменить заголовок, вступление, изображения, названия, описание и состав оборудования. Карточки можно дублировать, удалять и переставлять. Изображения выбираются из медиатеки; ссылки и дополнительные сведения добавляются стандартными средствами редактора.
4. Для каждого блока отдельно включить **Показывать на сайте** в боковой панели настроек блока и сохранить главную страницу. Для повторного скрытия выключить переключатель. Все внутренние блоки сохраняются в базе WordPress, даже когда раздел скрыт.

Отключённые разделы не выводятся сервером в публичный HTML. Скрытие не зависит от JavaScript или CSS. Стандартное сохранение страницы и права редактора обрабатывает WordPress; модуль не добавляет собственных запросов сохранения или API.

Стили подключаются к обоим блокам и используют палитру/шрифты будущей темы. Локальные шрифты и основные стили сайта нужно перенести вместе с темой согласно `CMS-MIGRATION.md`.

Текущие демонстрационные проекты не импортируются автоматически. Их исходные данные сохранены отдельно в `data/showcase.json`, шаблоны статической версии — `casesSection()` и `partnersSection()` в `assets/app.js`.

После установки в целевой WordPress проверить отображение в редакторе, сохранение страницы, оба переключателя и стили темы. Модуль подготовлен отдельно от переноса всего сайта и не устанавливает тему или каталог.

Основа реализации: [метаданные блоков](https://developer.wordpress.org/block-editor/reference-guides/block-api/block-metadata/), [редактируемые вложенные блоки](https://developer.wordpress.org/block-editor/how-to-guides/block-tutorial/nested-blocks-inner-blocks/), [серверная регистрация](https://developer.wordpress.org/reference/functions/register_block_type/).
