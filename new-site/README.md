# Мольберты.ру — локальный вариант сайта

## Запуск

```bash
cd /home/v_chernyshov/molberty/new-site
python3 serve.py
```

Откройте http://127.0.0.1:4173/ . Остановка — Ctrl+C. Если порт занят: `python3 serve.py --port 4174`.

Также можно запустить `npm start`. Установка пакетов для работы сайта не нужна. Изображения, шрифты и скрипты находятся в папке assets. Страницы и каталог работают локально; интерактивная карта и документы в Google Drive требуют подключения к интернету.

## Что готово

- Главная с уникальной композицией, текстами, иконками и изображениями.
- Каталог по «Структура.doc»: пять основных разделов, 34 категории с вложенностью, 91 товар с исходными названиями, описаниями и всеми фотографиями.
- Поиск, фильтры материала, полки и двусторонних моделей, сортировка по названию и цене, сброс, вложенное меню.
- Карточки и быстрый просмотр: розница/опт, комплектация, планшеты, пересчёт стоимости, корзина с отдельными вариантами и сохранением в браузере.
- Подбор по трём вопросам.
- Блог `/blog/` и четыре статьи с полными оригинальными текстами и изображениями исходного сайта: конструкции, интерьер, история мастерской. «Как выбрать мольберт» перенесено отдельной статьёй с исходной страницы /how_to_make_choice.
- Мастерская, контакты, руководство по выбору, доставка и оплата заказа, описание обработки данных.
- Подготовка обращения: черновик, открытие письма, скачивание текста. Заказ оформляется как подготовленное письмо; серверная отправка и онлайн-оплата не подключены.
- Чек-лист и CSV-шаблон списка оборудования скачиваются без передачи контактов.
- Адаптивные экраны и единые компоненты на всех страницах.

Итого: 138 страниц содержимого и 25 страниц перехода с прежних адресов карточек и объединённых категорий. Шесть ранее удалённых общих категорий остаются недоступны; вложенные разделы мини-мольбертов и новый раздел столов созданы по документу.

- `data/catalog-structure.doc` — копия «Структура.doc», актуальная иерархия. Машиночитаемая структура — `data/catalog-structure.json`, извлечённый текст — `data/catalog-structure.txt`. XLSX использована на первоначальном этапе; текущую иерархию задаёт Word-документ.

Основные тексты написаны заново; оригинальное описание компании и следующий за ним текст, названия и описания товаров перенесены без сокращений по отдельному запросу. Не заимствованы отзывы, клиенты, кейсы и обещания сроков из референса. Вместо неподтверждённых кейсов — сценарии применения. На странице /prices/ приведены 106 позиций из Praiss_total_2026.pdf с отдельными оптовыми и розничными ценами. Дата прайса — 01.01.2026. Карточки используют цены из исходного интернет-каталога и рассчитывают стоимость выбранной комплектации. Цены из PDF на /prices/ сохранены отдельно: источники могут отличаться.

Для всех 91 товаров используются фотографии конкретных моделей с molberty.ru: 202 фотографии (202 уникальных исходных изображения) в assets/catalog. Исходные ссылки, названия, описания и варианты — в data/products-source.json. Файлы оптимизированы в WebP без изменения конструкции изделий. Использованы оригинальные файлы моделей с исходного сайта; текущая выгрузка сверена с полными страницами каталога от 21.10.2026.

Фотоблок производства, главный экран и иллюстрации концептуальных объектов созданы с помощью imagegen. Внутри статей используются оригинальные изображения molberty.ru, а для анонсов и обложек созданы тематические иллюстрации. Производственные изображения — фотовизуализации, а не документальная съёмка мастерской. Названия объектов и кейсы вымышлены и явно отмечены как концепции. Перед публичным запуском их следует наполнить подтверждёнными проектами. SVG-иконки и схемы нарисованы специально для проекта.

## Структура

- `assets/app.js` — общие компоненты, страницы, интерактивность.
- `assets/style.css` — единая дизайн-система, адаптивные правила.
- `data/catalog.json` — каталог и статьи для переноса в CMS.
- `data/articles.json` — редактируемые статьи с разделами, источниками и сведениями об оригинальных публикациях.
- `assets/data.js` — браузерная версия каталога.
- `scripts/build.py` — создание маршрутов и итогового каталога по Word-структуре и проверенному распределению товаров.
- `scripts/draw.py` — генерация авторских SVG-схем.
- `scripts/prerender.cjs` — необязательная предварительная отрисовка HTML (требует Playwright и работающего локального сервера).
- `CMS-MIGRATION.md` — рекомендации для WordPress/Битрикс.
- `qa/` — снимки desktop/mobile и протокол проверки.

Пересборка базовых страниц: `npm run build` (Python 3, исходная XLSX рядом с папкой). Проверка: `npm run check`. JavaScript работает без сборщика и сторонних библиотек. В поставке страницы уже предварительно отрисованы в HTML. После пересборки шаблонов при необходимости повторите `node scripts/prerender.cjs` с установленным Playwright и работающим сервером. Локальная версия закрыта от индексации метатегом robots; для публикации его необходимо изменить.

## Оформление статей и тематические анонсы

Оригинал в data/articles.json не изменяется при оформлении. Отдельный data/article-presentation.json задаёт главы (id, title, start/end по индексам исходных блоков), списки, выделения, короткий анонс, время чтения и тематическое изображение. scripts/build.py объединяет эти данные в браузерный каталог. Все 15 исходных иллюстраций и подписи остаются на своих местах.

## Общие плавные эффекты

Дополнительный общий слой — assets/motion.css и assets/motion.js. Подключать motion.css после style.css, а motion.js — после app.js на каждой странице. Ссылки, кнопки, карточки, изображения, поля, меню и раскрывающиеся блоки используют согласованные интервалы 180/260/420 мс. Анимация не задерживает изменение данных или расчёт цены. Фон категорий на главной при наведении остаётся белым.

Web Animations API обеспечивает открытие/закрытие диалогов, раскрытие details, смену изображений и результатов фильтра. Нативные ссылки, формы и details сохраняются; при отсутствии API оформление не мешает работе. Закрытое мобильное меню исключается из фокуса через inert; Escape возвращает фокус кнопке меню. Режим prefers-reduced-motion отключает анимации и плавную прокрутку, в том числе при переключении настройки во время работы. Не заменять этот слой без учёта закрытия попапов, смены размеров экрана и быстрого повторного нажатия.

Переходы по внутренним ссылкам дополнительно используют короткое межстраничное растворение через @view-transition там, где браузер его поддерживает; обычная навигация сохраняется. В режиме уменьшения движения эффект выключен. Описание механизма: https://developer.chrome.com/docs/web-platform/view-transitions/cross-document . Проверки нового слоя: scripts/test-motion.cjs и qa/motion-test-result.json; проверены обратимые раскрытия, закрытие/повторное открытие попапов, Escape, фокус меню, режим reduced motion и отсутствие Web Animations API.


## Появление блоков при прокрутке

Общий `assets/motion.js` добавляет однократное появление заголовков, карточек, изображений и крупных информационных блоков через IntersectionObserver и Web Animations API. Сетки получают небольшую задержку между соседними элементами (не более 180 мс, на телефонах — 100 мс). Первый экран появляется за 340 мс; остальные блоки — за 420 мс на телефонах и 520 мс на больших экранах, со смещением 8–18 px. Для смещения используется отдельное свойство translate, поэтому эффект не конфликтует с transform при наведении.

HTML и CSS не скрывают контент до запуска скриптов. Если JavaScript, IntersectionObserver или Web Animations API недоступны, все блоки остаются видимыми. В фокусе клавиатуры содержимое сразу показывается полностью. Уменьшение движения, печать и уход со страницы отменяют появления; возврат к странице и переключение предпочтения обрабатываются без повторного проигрывания просмотренных карточек. После фильтрации видимые результаты используют короткое растворение, а появление нижних карточек срабатывает при прокрутке. Длительные и зацикленные эффекты не используются.

Проверки: `scripts/test-scroll-motion.cjs` и `qa/scroll-motion-test-result.json`; прежние интерактивные проверки — `scripts/test-motion.cjs`. Сохранены единое оформление карточек, отсутствие отступов у фотографий, белый фон категорий при наведении и скрытый мобильный сайдбар.
