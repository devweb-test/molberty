# Мольберты.ру — пакет переноса на WordPress

Согласованный эталон: v129 от 12 ноября 2026 года. Публичный просмотр: https://devweb-test.github.io/molberty/new-site/

Пакет подготовлен для вебмастера, который выполняет перенос с Codex. Это исходники, данные, инструменты импорта и техническое задание. Готовая тема WordPress, рабочая обработка заказов и установленная CMS должны быть реализованы на этапе переноса.

## Начать здесь

1. Прочитать AGENTS.md, затем docs/01-PLAN.md.
2. Открыть контрольный сайт локально: npm --prefix reference/new-site start. В архиве он находится в reference/new-site; в исходном репозитории — в соседней папке new-site. Адрес просмотра — http://127.0.0.1:4173/.
3. Проверить целостность: python3 tools/validate_package.py
4. Проверить эталон: npm --prefix reference/new-site run check
5. Передать Codex стартовое задание из docs/08-CODEX-TASKS.md.
6. Разрабатывать в отдельной папке wordpress-site и на staging. Не изменять папку эталона.

В репозитории пути к эталону заменяются с reference/new-site на ../new-site. Инструменты определяют оба расположения автоматически; явный параметр --source снимает неоднозначность.

Для локальных инструментов нужны Python 3.11+, Node.js поддерживаемой LTS-ветки и PHP 8.3+. Генераторы JSON/CSV/Office используют стандартную библиотеку Python; установка Python-пакетов не требуется. WP-CLI и WordPress/WooCommerce нужны только для применения импорта на целевом staging.

## Что внутри

- docs/ — пошаговый план, архитектура, карта данных, интерфейс, SEO, формы, запуск и задания Codex.
- exports/ — нормализованные JSON; sourceId и id сохранены; 717 контрольных расчётов цен.
- content/ — итоговый main всех 142 страниц, оригинальный оформленный текст статей и общие элементы. Это материал для переноса в шаблоны, а не готовые PHP-шаблоны.
- tables/ — CSV в UTF-8 с BOM: URL/SEO, категории, товары, медиа и редиректы.
- wordpress/molberty-migration-tools/ — вспомогательный плагин WP-CLI: повторяемый импорт в черновики и проверка результатов.
- wordpress/molberty-home-blocks.zip — имеющийся модуль Gutenberg для кейсов и примеров пространств.
- integration/ — конфигурации известных редиректов и обработчик старых Tilda-ссылок с фрагментом.
- config/project.example.json — параметры проекта без паролей и ключей.
- reference/ — полная неизменённая версия v129 в ZIP-пакете, включая фотографии, логотипы, шрифты, PDF и прежние QA-материалы.
- source-documents/ — исходная структура, SEO-таблицы, список контрагентов и документы заказчика.
- checks/ — контрольные суммы, результаты подготовки и самопроверки пакета.
- План переноса на WordPress.docx — инструкция для чтения вне редактора кода.
- Карта переноса.xlsx — сводная книга для проверки данных и приёмки.

## Приоритет источников

Текущий пакет и итоговый HTML v129 важнее исторических README.md и CMS-MIGRATION.md внутри эталона: старые файлы ведутся как журнал изменений и местами описывают отменённые решения. Не запускать npm run build или полный prerender эталона: они могут пересоздать ранее согласованную разметку.

## Граница готовности

В комплекте нет доступа к хостингу, установленного WordPress, SMTP, CRM или платёжного шлюза. В эталоне формы демонстрационные. Импортер создаёт черновики, сохраняет исходные поля и не реализует публичный магазин, ценовой движок, SEO-плагин или конечную тему. Проверки в checks показывают только фактически выполненные проверки; работу в целевом WordPress вебмастер проверяет отдельно.

Исходный snapshot.json и SHA256SUMS.txt фиксируют состав передачи. Код, выгрузки и инструкции сохранены также в репозитории devweb-test/molberty, папка wordpress-migration. Большой неизменяемый reference и оригинальные source-documents доступны в полном ZIP; в репозитории эталон расположен в соседней папке new-site.
