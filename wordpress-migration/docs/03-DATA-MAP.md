## Стабильные ключи

Товар: id для внутренних ссылок, sourceId для повторного импорта, slug для публичного URL. Не вычислять slug заново из переводов или WordPress title. Один товар может относиться к нескольким категориям. Первичная категория берётся из primaryCategoryId и задаёт хлебные крошки.

Термы сопоставляются по id/slug и meta _molberty_category_id. Записи — по meta _molberty_source_key либо sourceId. Дубли, конфликт slug/SKU, отсутствующая категория или медиа — ошибка импорта с отчётом, а не повод объединить записи по похожему названию.

Вспомогательный импорт не удаляет записи, отсутствующие во входном JSON, и не меняет утверждённые записи в базе без отдельного --update-existing. Для опубликованной базы предпочтительнее отдельный проверенный план обновления, а не повторный первоначальный импорт.

## Товар и имя

WooCommerce title при первоначальном импорте получает итоговый h1. Оригинальное имя для листинга сохраняется в _molberty_original_name. Например: карточка — Мольберт Большой станковый (бук), листинг — Большой станковый (бук). Во всех наименованиях товара уже удалены кавычки.

Материал берётся из material/features.materials; не подставлять название предприятия. isNew формирует плашку Новинка оранжевого цвета. Описание и характеристики — исходные description/descriptionHtml, без выдуманных параметров.

## Цена и варианты

priceOptionIndex, retailSizeOptionIndex, wholesaleSizeOptionIndex могут быть 0. Проверять null строго; не использовать empty() для индексов.

Вариант mode=absolute заменяет базовую цену, delta прибавляет надбавку, none не меняет цену. Пустые варианты не выводятся. Если в группе есть absolute, интерфейс использует соответствующие варианты этой группы. Опции с priceTier показываются только в выбранном режиме.

Базу выбирают по рознице/опту, затем активные absolute, затем сумму delta. Оптовый минимум — max(minimumOrder, wholesaleMin). Для wholesaleOnly нельзя включить розницу. По умолчанию в листинге и карточке используется оптовый режим, если он доступен; defaultTier/defaultQuantity/listingPrice уже вычислены в выгрузке.

Флаг От берётся из согласованного поведения: оптовый режим показывает От; для розницы открытая цена определяется retailFrom. Не восстанавливать старые заметки о розничной цене по умолчанию. Сортировать по listingPrice. 717 fixtures созданы самим алгоритмом эталона; выполнить их и в PHP, и на связке UI/заказ.

## Статьи

Оригинальный текст не переписывать. Заголовки глав и содержание уже оформлены. В оформленном тексте исправлены изображения Лиры, А-класс и А-профи. Внешних ссылок в теле статей нет. Автор/журнал/год оригинала сохраняются отдельно от даты импортирования; не выдавать текущую дату за дату первоначальной публикации.

## Медиа и токены HTML

В нормализованном контенте {{asset}}/path означает файл assets/path эталона. {{site}}/route означает внутренний URL на целевом сайте. Импортер заменяет эти токены на URL медиатеки или локального файла темы, и home_url соответственно. В reference/main HTML остаются исходные относительные пути для сверки.

Медиа-импорт повторяется по относительному пути и SHA256. Если тот же путь имеет другой hash, остановиться и подготовить отдельное обновление файла. Не скачивать заново исходные фотографии с Tilda, если локальный файл уже есть. Внешняя сеть не нужна для импорта изображений.

## Примеры и отзывы

showcase хранит fictional=true; reviews относятся к макету и сохраняются с is_demo=true в meta. Эти внутренние признаки не удалять при импорте. Отдельно хранятся настоящие clients и их подтверждённые ссылки. Готовый эталон и содержимое этих блоков переносить как согласовано; внутренние признаки не являются заданием добавлять новые предупреждения в интерфейс.

## Прайс

7 разделов, 106 строк. price-product-links связывает 105 строк с 88 товарами. Строка Модерн без карточки. Null отображается как тире; оптовая и розничная цены независимы. Не заменять весь прайс динамическим списком 91 товара: состав прайс-листа отличается.

## Правило при расхождениях

Данные v129 и exports/routes.json имеют приоритет над историческими заметками. Число или опцию, которая выглядит подозрительно, зафиксировать в issues.md и сверить с заказчиком, не менять автоматически. Например, цена в подписи варианта может отличаться от его числового поля; расчёт использует числовое значение выгрузки.
