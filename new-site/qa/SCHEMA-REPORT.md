Разметка включена в head исходного HTML до выполнения JavaScript. При смене режима цены или комплектации карточка синхронно обновляет Offer. Быстрый просмотр не добавляет отдельную Product-разметку на страницу категории.

Рейтинги, отзывы, наличие, срок действия цены и доставка не добавлялись: источник не даёт надёжных данных для этих свойств. Главная содержит логическую цепочку из одного элемента; расширенные хлебные крошки требуют более длинной цепочки. Локальная копия закрыта noindex — это вариант для согласования и переноса в CMS.

Проверены локальные JSON и соответствие содержимому, а не публичная выдача Google. После переноса проверить доступные поисковику страницы в Rich Results Test и Schema Markup Validator. Гарантия расширенных результатов не подразумевается.

Примеры: generated-schema.json. Проверка: npm run check, scripts/test-shop.cjs и scripts/test-structure.cjs. Источники правил: https://developers.google.com/search/docs/appearance/structured-data/product-snippet и https://developers.google.com/search/docs/appearance/structured-data/breadcrumb .
