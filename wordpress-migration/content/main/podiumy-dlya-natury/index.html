Подиумы для натурщика и учебных постановок

При выборе подиума исходят из постановки: будет ли это позирование натурщика или размещение предметов для учебного задания. Нужную длину и ширину определяют вместе с расположением рабочих мест и обзором композиции. Площадку изготавливают по размерам заказчика, поэтому параметры можно обсудить под конкретное помещение.

Конструкция выполнена из фанеры на деревянном каркасе и предусматривает регулируемые мебельные опоры. Покрытие, возможность настила ковролина и требуемую высоту укажите в заявке. Если для постановок нужен отдельный фон, опишите его вместе с габаритами подиума, чтобы согласовать весь участок экспозиции.
