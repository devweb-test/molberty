Мебель для занятий сидя подбирают к тому месту, где будет работать художник: обычному столу или мольберту с поднятым лотком. В группе есть рабочий табурет, высокие табуреты и стул художника. Начните с нужной высоты сиденья, затем проверьте ширину, глубину и место для расположения ног.

При оснащении нескольких кабинетов полезно разделить посадочные места по назначению, а не заказывать один вариант для всех задач. Сосновые и буковые исполнения можно сравнить с остальной мебелью по материалу и внешнему виду. Для оптовой партии уточните также вид поставки: он указан в описании изделия.

Советы ПЕРЕД ВЫБОРОМ

Удобная мебель для сидения.

01

Выберите необходимую высоту табурета.

Для детских студий достаточно стандартной высоты 45 см.

02

Выберите материал изготовления мебели.

Сосна более лёгкая. Бук — тяжелее и прочнее.

03

Согласуйте детали.

Укажите нужную высоту, материал и количество изделий — согласуем исполнение и комплектацию.

Передайте нужные высоты сидений и количество мест — согласуем комплект мебели для занятий.
